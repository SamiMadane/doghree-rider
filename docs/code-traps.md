# Code traps

Non-obvious pitfalls in this codebase. Add an entry when one costs time.

| Trap | Where | Why it bites | Safe pattern |
|---|---|---|---|
| `flutter run` / `flutter test` regenerate plugin registrants | macos/Flutter/GeneratedPluginRegistrant.swift, windows/flutter/generated_plugin_registrant.cc, windows/flutter/generated_plugins.cmake | They show up as modified after any Flutter run and can slip into a batch commit | Never stage them in a batch. `git restore` them before merging (D-01) |
| Logout ordering: no server call runs during logout | lib/features/auth/domain/repositories/auth_repository.dart `clearSharedData` | Since D-03 logout sends no `update-fcm-token`, because the server requires `fcm_token` and the old call always failed. The device is released through `deleteToken` instead. `clearSharedData` clears the token and header first, then runs the FCM cleanup. The rider token goes only in the Bearer header, and `postData` takes the headers when it is called, so a server call added after the clear goes out without auth (401) | If a logout server call is ever reintroduced, start it before the token and header are cleared and use `handleError: false`. Keep the FCM cleanup bounded (5 s) and keep the pending flag, so an offline logout is retried (D-02, D-03) |
| `updateToken` is gated by the notification setting | auth_repository.dart `updateToken`, `setNotificationActive` | `updateToken` returns early while the notification setting is off. A toggle-on that called it before saving `true` would register nothing | `setNotificationActive` saves the setting first, then calls `updateToken` (D-03) |
| `ProfileModel.fromJson` throws on a missing list | lib/features/profile/domain/models/profile_model.dart (`identity_image_full_url`) | `json['identity_image_full_url'].cast<String>()` throws when the field is null or missing, so a 200 response can still fail to parse | Callers must catch parse errors. `ProfileRepository.getProfileInfo` maps a parse error to `SessionStatus.unverified` (D-01). Tests must include the field |
